# عالم الرياضيات — نسخة GitHub Pages وقالب Blogger

هذه نسخة ثابتة خفيفة لبوابة تعليمية عربية مخصصة للمرحلة الثانوية في المنهج اليمني. تعمل ملفات الجذر مباشرة على GitHub Pages، ولا تحتاج إلى خادم أو قاعدة بيانات.

## تشغيل النسخة الثابتة

ارفع محتويات مجلد المشروع إلى مستودع GitHub، ثم فعّل **GitHub Pages** من الفرع الذي يحتوي `index.html`. تفتح الصفحة الرئيسة مباشرة، وتنتقل بقية الصفحات عبر ملفات HTML وروابط المعلمات مثل `grade.html?grade=second`.

## إدارة المحتوى

تنقسم الموارد إلى مسارين مستقلين. تُدار شروح الدروس في `content/site-data.js` في نسخة GitHub Pages، ويمكن استبدالها في Blogger بمنشورات أو صفحات دروس مستقلة. أما ملخصات الوحدات وملخص المنهج فهي موارد PDF مرجعية، ويُربط كل ملف من أزرار صفحة `summaries.html` بعد رفعه إلى Blogger أو إلى مستودع GitHub.

## الاختبارات والألعاب

يضم الموقع نموذج اختبار ولعبة مفاهيم. الأسئلة التجريبية موجودة في `content/site-data.js`. تحفظ أفضل نتيجة للاختبار في متصفح الطالب باستخدام `localStorage` فقط، من دون حسابات أو إرسال معلومات إلى خادم.

## Blogger

يحتوي مجلد `blogger/` على قالب XML قابل للرفع، وصفحة هبوط HTML لإدراجها في صفحة Blogger ثابتة. اقرأ `blogger/README.md` قبل الرفع؛ ستحتاج إلى نسخ ملف CSS وJavaScript إلى القالب أو استخدام نسخ Blogger المدمجة المرفقة.
